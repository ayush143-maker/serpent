# serpent

**SERPENT** is a browser-based take on the classic Snake game. The page includes a play area, current and best scores, pause and play controls, and on-screen guidance for keyboard and touch-style movement. Follow that guidance to control the snake.

## Play locally

No package installation is needed. Open `index.html` in a modern browser, or run a local server from the project folder:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000.
