# serpent

**SERPENT** is a browser-based take on the classic Snake game. The project consists of the single HTML page `index.html`, which contains a play area, current and best scores, pause and play controls, and on-screen guidance for keyboard and touch-style movement. Follow that guidance to control the snake.

## Play and review locally

No package installation is needed. Open `index.html` in a modern browser, or run a local server from the project folder:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000. For a small change, edit `index.html`, reload the page, and use its on-screen guidance and controls to review the result.
